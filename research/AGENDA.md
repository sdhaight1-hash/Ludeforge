# Phase 0 research agenda

| Topic | Candidate references | Questions / deliverable |
|---|---|---|
| Rule authoring | Quest Bound, Grimory, LoreKit | Entity schemas, authoring experience, extension points, limitations |
| General descriptions | Ludii, Micro-Machinations | Minimal primitives, semantics, expressiveness boundaries |
| Feedback analysis | Machinations, Mechflow | Resource flow, loops, exploit detection and bounds |
| Stochastic mechanics | Icepool, dyce, AnyDice, Troll | Exact distributions, explosion limits, numerical representation, differential tests |
| State and replay | Ancient Draconic, event sourcing literature | Atomic events, versioning, deterministic traces, human checkpoints |
| Publication | RuleBindery | Structured references, generated documents, revision workflow |
| Local-first storage | SQLite, portable structured files | Authority, atomic writes, migrations, diffs, corruption recovery |
| Visual authoring | Graph editing and HCI research | Typed nodes, diagnostics, round trips and designer accessibility |
| Evaluation | MDA, design science, game testing | Metrics, baselines, participant tasks, simulation validity |

For every reference: verify existence, maturity, source and license; classify reuse vs conceptual inspiration; record reproducible findings and impact on an issue or ADR. No dependency is approved by inclusion here.
