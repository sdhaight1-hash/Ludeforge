# Research program

The [thesis bibliography](../THESIS.md#23-primary-research-bibliography) is the starting corpus, not a completed literature review. Verify papers, project documentation, repository activity and licensing before relying on claims.

Record each investigation in a dated or topical Markdown note with question, method, source URLs, access date, observed facts, limitations, alternatives, applicability to Ludeforge, and proposed next experiments. Distinguish source observations from design inference; do not copy code or unlicensed rules text.

See [research agenda](AGENDA.md) and [evaluation protocol](EVALUATION.md).
