## Standards and competing choices

- [CEL overview](https://cel.dev/overview/cel-overview): parse/check/evaluate separation; typed AST reused at runtime. Prefer an original minimal typed AST, not embedded general scripting. A terminating expression language still needs explicit cost bounds; functions and collections can amplify work.
- [SHACL](https://www.w3.org/TR/shacl/): shape constraints and structured reports over immutable data and shapes during validation. Borrow shape/diagnostic separation, not RDF/OWL inference. Closed-world authored game constraints differ from open-world knowledge inference.
- [JSON Schema 2020-12](https://json-schema.org/draft/2020-12/json-schema-validation): structural validation, enum and array constraints. It does not alone enforce project-specific cross-object ID uniqueness, typed references, or expression semantics. Use Rust semantic validation behind format validation.
- [RFC 8259](https://www.rfc-editor.org/rfc/rfc8259): duplicate JSON keys cause interoperability problems; reject at parse time before mapping. [RFC 8785](https://www.rfc-editor.org/rfc/rfc8785): canonicalization uses I-JSON and precise number/string rules; safe integer cross-language range and canonical hashes must be explicit. Do not call sorted-key JSON RFC-compliant without conformance.
- [SQLite atomic commit](https://www.sqlite.org/atomiccommit.html): transaction durability depends on storage assumptions and journal mode. Evaluate as alternative authoritative store or derived index; no claims of file-replacement crash durability.
- [Ludii](https://ludii.games/): composable descriptions of games provide a precedent for small reusable operations. Human-mediated TTRPG decisions remain outside closed game-state assumptions.

## Results

[Original executable feasibility check](prototypes/kernel-check.mjs) was run in a JavaScript execution environment. [Captured output](prototypes/kernel-check-results.json). It explores a finite abstract authorization protocol to exhaustion and detects deliberately faulty transitions; compares integer-count convolution with independent recursive enumeration across six dice sets; checks three original expected outcomes. No production implementation, full formal proof, or performance comparison is claimed.

Baseline: 22 reachable states and 154 outgoing transitions; no checked violation. Four deliberately faulty variants each produced counterexamples. 182 exact bins and 200 threshold comparisons agreed. Scope is one request, abstract fixed identities, no concurrency or persistence, bounded revisions, uniform independent dice. The prototype does not verify full proposed contracts. A later production implementation needs independently authored conformance tests, file-failure injection and multi-request traces.
